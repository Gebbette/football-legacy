PRIVACY BY DEFAULT

Privacy & storage

A plain-English explanation of what the website stores, what it does not collect, and how you stay in control.

The short version

Football Legacy does not ask you to create an account.
The game does not contain advertising, behavioural profiling or location tracking. It uses Cloudflare Web Analytics and Plausible Analytics for aggregate website usage, engagement and performance statistics.
Your career saves are stored in your browser on your device. They are not sent to Football Legacy.
You can delete Football Legacy save data from this page at any time.

Privacy notice

What Football Legacy intentionally collects

Football Legacy itself does not ask you to provide your name, email address, date of birth, precise location, contacts or payment details. There are currently no accounts, comments, chat rooms or advertising systems. The site uses Cloudflare Web Analytics and Plausible Analytics to understand aggregate page usage, visit engagement and website performance.

Cloudflare Web Analytics

Football Legacy uses Cloudflare Web Analytics to measure aggregate website usage and performance, such as page views and Core Web Vitals. Cloudflare states that Web Analytics does not collect or use visitors' personal data and does not use cookies or localStorage to collect usage metrics. The analytics beacon is loaded from static.cloudflareinsights.com and, because this site is hosted on GitHub Pages rather than proxied through Cloudflare, analytics reports are sent to cloudflareinsights.com. Football Legacy uses these statistics to understand how the site is used and to improve performance; they are not used for advertising or behavioural profiling.

Game saves and browser storage

Career saves and game settings use local browser storage so the game can remember a career you asked it to save. This information stays in your browser unless you choose to copy or share a career result yourself. Clearing browser/site data may permanently remove saves.

Hosting

The website is hosted using GitHub Pages. Like other web hosts, GitHub may process technical connection information needed to deliver and secure the website under its own privacy terms. Separately, Football Legacy receives aggregate website statistics through Cloudflare Web Analytics as described above; game career saves themselves are not sent to Football Legacy analytics.

Children and teenagers

Football Legacy is designed to be playable without giving us personal information. Privacy is therefore set high by default: no public profile, no direct messages, no targeted ads, no location tracking and no profiling for advertising. If these features ever change, this notice must be updated before the new processing starts.

Sharing

The game may offer a Share or Copy Result button. Nothing is shared automatically. Your device's own share sheet only opens after you choose to use it, and you decide where the result goes.

How long data is kept

Football Legacy does not set a server retention period for game saves because it does not receive them. Browser save data remains on your device until the game or browser removes it, or until you clear it.

Your control

You can remove Football Legacy browser saves below. This only removes keys used by Football Legacy on this domain; it does not clear unrelated browser data.

Contact

For a privacy concern or bug report, use the public project contact route on GitHub rather than posting private information in a public issue. Do not include passwords, home addresses or other sensitive information.

Analytics providers

Cloudflare Web Analytics is used for aggregate traffic and performance measurement.

Plausible Analytics is used for aggregate traffic and engagement measurement, including metrics such as page views, visits, referral sources, device categories and visit duration. Football Legacy does not send Plausible your career-save contents, name, email address or other information you type into the game.

These analytics services are used to understand overall trends rather than to build advertising profiles of individual players.

Storage technologies

Football Legacy uses browser storage for requested game functionality such as saving a career. It also uses Cloudflare Web Analytics and Plausible Analytics for aggregate site measurement. Both are used without advertising cookies or behavioural profiling. Plausible states that its hosted analytics does not use cookies, browser cache or local storage for visitor tracking, and does not store raw IP addresses. The site does not use advertising pixels or social-media tracking technologies.

If advertising, embedded social trackers, account profiling, or analytics technologies that use cookies or other client-side identifiers are added later, the privacy/storage design and any consent requirements will be reviewed before they go live.
