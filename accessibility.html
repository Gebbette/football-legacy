Accessibility

How Football Legacy is being tested and improved for different devices and accessibility needs.

Accessibility approach

Football Legacy aims to be usable on phones, tablets and desktop browsers, including with keyboard navigation and browser zoom. The website uses responsive layouts, visible focus styles, text labels on key controls and reduced-motion support in parts of the game.

Current status

The website has been checked with automated browser tests and manual responsive/keyboard checks, but it has not yet received an independent WCAG 2.2 AA audit. For that reason, this page does not claim full WCAG conformance.

Known areas to keep improving

  • Complex game screens contain dense information and may require additional screen-reader labelling.
  • Some animated match/trophy presentation may still be visually busy even where reduced motion is supported.
  • Colour is supplemented with letters, scores or text where practical, but continued testing is needed.
  • Long career screens should continue to be tested at large text sizes and high zoom.

Browser zoom

Website pages do not intentionally disable pinch-to-zoom. The Website Ready build removes the previous maximum-scale restriction from the long career modes.

Feedback

If a control is difficult to use with a keyboard, screen reader, zoom or another accessibility tool, report the page and control that caused the problem without including unnecessary personal information.
